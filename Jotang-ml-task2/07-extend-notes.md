# 扩展2/3/4 实验回答

# 扩展2：预训练模型浅层 vs 深层特征（ResNet-18）

### 1. 第一层特征图的通道响应有什么特点？

第一层 64 个通道绝大多数都有明显响应（L2 范数多在几十到几百），只有极少数接近 0 的"死通道"；而且响应强的通道集合在不同照片之间高度相似——说明第一层学的是边缘、颜色块这类通用底层特征，不挑图片内容。

### 2. 最后一层呢？和第一层有什么不同？

最后一层 512 个通道里只有少数响应强，大部分接近 0。另外特征图空间只有 4×4（第一层是 64×64），又经过多层 ReLU 和 BatchNorm，L2 绝对值比第一层小两个数量级，所以对比时看的是响应的相对分布（降序排序后的曲线形状），而不是绝对数值。

### 3. 不同图片在最后一层的激活有什么差异？

不同图片激活的通道集合明显不同——最后一层通道对应 ImageNet 学到的语义概念（某种纹理、物体部件等），图片内容不同，触发"专职探测器"的子集自然不同。

## 扩展3：Bottleneck 改造实验

### 1. 参数量的变化？

Bottleneck 把卷积参数量降到原来的 69.17%（23,584 → 16,312），但总参数量几乎没变（2,120,993 → 2,113,721）：卷积再省，全连接层才是参数大户，全连接没动，总参数就降不下去。

### 2. 训练速度的变化？

每轮 Bottleneck 大约慢 0.4 秒（22.3s → 22.7s）：层数变多，GPU 要跑更多小算子，开销反而略增。

### 3. 精度的变化？

原版更高。对比表（test acc）：原版 0.8709 > Bottleneck+BN 0.8253 > 裸 Bottleneck 0.7737。而且裸 Bottleneck 跨次运行结果不稳定：第一次训练 loss 钉死在 0.6932（正好是 ln2，二分类瞎猜的损失），test 只有 0.4962，完全没学起来；第二次重跑才到 0.7737。没有 BN 时，训练结果要看初始化的运气。

### 结论

1×1→3×3→1×1 这个结构本身不是问题（加上 BN 就能正常训练），真正缺的是 BN 带来的训练稳定性；但在这只有 3 个块的小网络上，加深带来的优化难度超过收益，还不如原来的简单结构。这也符合题目的提示：Bottleneck 是为几十上百层的深网络设计的省参数手段，小网络用不上。另外原版两次运行 test 是 0.8645 / 0.8709，本身也有 ±0.6 个百分点的波动——1 个百分点以内的差距不足以下结论。

## 扩展4：手搓 ResNet-18

### 1. 手搓版的参数量和论文对得上吗？

手搓版参数量 11,689,512，和论文的 11.69M 基本一致，说明结构搭对了。

### 2. 特征图尺寸从 224 一路变到 7，每次减半发生在哪里？

前两次减半在 stem：7×7 卷积 stride=2 管 224→112，MaxPool stride=2 管 112→56。后三次减半是 layer2/3/4 各自第一个 BasicBlock 的 stride=2 干的：56→28→14→7，正好五次减半。layer1 的 stride=1，尺寸不变。

### 3. 残差捷径的作用？去掉会怎样？

残差捷径解决深度网络的退化问题。如果去掉捷径，训练误差可能上升，梯度也更容易消失——网络深了之后，单纯堆层的优化难度会失控。这一点和扩展3的实验互相印证：裸 Bottleneck 多了几个 1×1 层就直接训不动，18 层的网络去掉捷径只会更严重。
