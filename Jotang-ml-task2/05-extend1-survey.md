# 扩展1：经典 CNN 调研（AlexNet / VGG / ResNet）

先摆数字对比（以 224×224 输入为例）：

| | AlexNet | VGG-16 | ResNet-18 |
|---|---|---|---|
| 层数 | 5 卷积 + 3 全连接 | 13 卷积 + 3 全连接 | 17 卷积 + 1 全连接 |
| 卷积核 | 11×11、5×5、3×3 混用 | 全部 3×3 | 3×3（BasicBlock） |
| 通道变化 | 96→256→384→384→256 | 64→128→256→512→512 | 64→128→256→512 |
| 特征图尺寸 | 55→27→13→13→6 | 224→7（5 次 MaxPool 减半） | 224→56→28→14→7→GAP |
| 参数量 | 约 6000 万 | 约 1.38 亿 | 约 1170 万 |

### AlexNet（2012，深度学习引爆点）

创新亮点：

1. 激活函数改用 ReLU，替代之前常用的 sigmoid，缓解深层网络的梯度饱和问题，训练速度提升数倍；
2. 引入 Dropout 随机失活和数据增强，抑制模型过拟合；
3. 使用双 GPU 并行训练，把网络拆分到两块显卡上，解决当年显卡算力不足的痛点。

### VGG（2014，极简主义代表）

VGG 最核心的思想是"小核堆叠"：用连续两个 3×3 卷积等效一个 5×5 的感受野，参数量更少、非线性更强，网络设计极其规整，像搭积木一样重复相同的模块。

创新亮点：

1. 整套网络统一只用 3×3 卷积核，设计极简，可扩展性很强；
2. 证明"把网络做深"是提升模型能力非常有效的手段。

教训：三个巨型全连接层带来了巨大参数量，VGG-16 一亿多参数绝大多数都集中在全连接层。这个沉重的代价催生了后续两个重要技术：1×1 卷积（Network in Network），以及全局平均池化（GoogLeNet、ResNet 使用）。

### ResNet（2015，残差连接）

ResNet 解决了困扰学界很久的网络退化问题：单纯把网络堆深，训练误差反而上升——这不是过拟合，而是优化困难。

创新亮点：

1. 残差捷径 y = F(x) + x：网络不再学习从 x 直接映射到 y，而是学习残差 F(x) = y − x，优化难度大幅降低，网络可以做到几十上百层；
2. BatchNorm 正式铺开，稳定训练，让深层网络收敛变得容易；
3. 用全局平均池化（GAP）替换巨型全连接层，大幅砍掉参数量，ResNet-18 的参数量比 VGG 小一个数量级。

### 三条演变主线

**故事线1（参数量）：6000 万 → 1.38 亿 → 1170 万。** AlexNet 6000 万参数；VGG 为了加深网络，加上三个巨大全连接层，参数量暴涨到 1.38 亿，代价沉重；ResNet 用 GAP 替代全连接，直接砍掉绝大部分参数，ResNet-18 仅 1170 万。这个演进说明：单纯靠堆全连接层扩容参数性价比很低，"卷积 + 全局池化"的方案用更少的参数就能获得很强的特征能力。

**故事线2（卷积核）：大核 11×11 → 统一小核 3×3 → Bottleneck 引入 1×1。** AlexNet 开头直接上 11×11 大卷积核；VGG 证明多个 3×3 堆叠性价比更高；ResNet 深层版本引入 Bottleneck 瓶颈结构：1×1 降维 + 3×3 特征提取 + 1×1 升维，利用 1×1 卷积压缩通道，大幅降低中间 3×3 卷积的计算量，让几百层网络的计算开销可控。

**故事线3（深度）：8 层 → 16 层 → 152 层。** AlexNet 仅 8 层；VGG 把深度推到 16、19 层，但发现继续加深效果反而变差；ResNet 依靠残差跳跃连接打通梯度回传通路，梯度可以跳过多个层直接回传，解决了深度退化问题，把网络上限拉高到上百层。从此"更深"成为 CV 模型提升能力最常用的思路。

**总结：** 从 AlexNet、VGG 再到 ResNet，这三条主线共同构成了现代 CNN 发展最核心的探索历程：从最早期验证深度学习的可行性，到尝试堆叠深度、踩下全连接参数爆炸的坑，最后依靠残差连接解决深度瓶颈，同时搭配 BN、全局池化、1×1 卷积等手段，奠定了后续计算机视觉网络的设计范式。
