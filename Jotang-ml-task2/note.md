# Task2 回答文档

## 实践1：卷积核（第 1、3、6 题）

### 1. 像素和 RGB 是什么？灰度图和彩色图有什么区别？

像素是图像里最小的一个格子单元，每个像素存亮度/颜色数值。RGB 是彩色图最常用的色彩模式，R=Red、G=Green、B=Blue 三个通道，通过三种颜色叠加，得到各种各样的颜色。灰度图只有一个通道，每个像素只存亮度，0 为黑，255 为纯白；彩色图有 3 个通道，每个像素有红绿蓝三组数值，可以还原丰富的颜色。

### 3. 卷积核是什么？它是怎么工作的？

卷积核是一个很小的权重矩阵（一般 3×3），里面预先存好一组数字权重，相当于一个"特征探测器"，用来在图片上找特定图案。卷积核从图片左上角开始，按设定好的 stride 步长，一行一行从左往右滑动。卷积核盖住的区域，对应位置的像素值 × 卷积核权重全部相加，得到的总和就是输出特征图上这个位置的数值。

### 6. 为什么均值/高斯卷积让图片变模糊，锐化让边缘更突出？Sobel 为什么能找到边缘？

均值卷积是窗口里所有像素取平均；高斯卷积是窗口中心像素权重高、越往外权重越低，本质还是局部加权平均。所以用平均或高斯卷积把一块区域里面的像素亮度做平均，像素之间的明暗差被抹平，原本明暗突变的边缘被弱化，细节被平滑，图片就变模糊。边缘是图片里明暗变化突然的地方，锐化会放大明暗之间的差值，把突变处的反差拉大，让边缘轮廓更突出。Sobel 是专门用来计算像素灰度梯度的卷积核，它的权重一般设计成一边正数、一边负数：如果区域亮度差不多，正负抵消，结果大约为 0；如果这里刚好是边缘（像素亮度剧烈变化），正负抵消不掉，算出的值就很大。所以输出值大的地方，就很可能存在边缘。

## 实践2：猫狗分类器（趁热打铁六问）

### 1. 卷积层和全连接层有什么区别？

卷积层看图片时每次只看一小块局部区域，而且一套卷积核是整张图共用的，所以自带平移不变性（图案出现在哪里都能被识别出来），再加上权重共享，参数量很小；全连接层的每个神经元要和上一层的所有数字相连，没有局部观察，也没有平移不变性，参数量一下就上去了。我的网络里 16384→128 这一层就占了总参数的绝大部分。

### 2. 通道数为什么这样设计（3→16→32→64）？

输入图片的原始通道是 3，随着网络往下走，图片分辨率不断缩小，特征图上每个像素对应的原图区域变大。大图阶段只提取边缘、线条这类简单特征，少量通道就够用；图变小之后，为了描述复杂多样的组合特征，就要增加通道数量，用更多不同的特征提取器来记录不同的图案。

### 3. 尺寸计算公式代入自己的网络

输出 = (输入 + 2×padding − kernel) / stride + 1。

- 卷积：我的网络里 kernel=3、padding=1、stride=1，代入得 (输入 + 2×1 − 3) / 1 + 1 = 输入，所以卷积不改变宽高；
- MaxPool：kernel=2、stride=2，代入得 (输入 + 0 − 2) / 2 + 1 = 输入 / 2，所以每次池化宽高减半。

128 进网络，池化三次后变成 16，通道涨到 64，最后 Flatten 得到 64×16×16 = 16384。

### 4. 为什么越深的层特征图越小、通道越多？

网络越深，经过多次池化压缩，特征图分辨率变小，但感受野更大，能表达的复杂特征种类也更多，所以需要更多通道来存放各种不同组合的特征信息。

### 5. 为什么最后输出一个数、损失函数用 BCEWithLogitsLoss？

这个任务是猫狗二分类，只需要输出一个数表示样本是狗的概率，所以最后用 Linear 到 1。BCEWithLogitsLoss 相当于把 sigmoid 和 BCE 合到一个函数里算，数值上更稳定：如果分开算，当数值落到 sigmoid 两端的饱和区时梯度会变得特别小，容易出现梯度消失。

### 6. 数据增强为什么只加在训练集？

训练集做数据增强是为了不让模型死记硬背，防止过拟合、提高泛化能力。如果验证集也增强，每次评测的数据都不一样，分数会忽高忽低，没有可比性，就没法判断模型到底有没有变好。

## 扩展1：经典 CNN 调研（AlexNet / VGG / ResNet）

先摆数字对比（以 224×224 输入为例）：

| | AlexNet | VGG-16 | ResNet-18 |
|---|---|---|---|
| 层数 | 5 卷积 + 3 全连接 | 13 卷积 + 3 全连接 | 17 卷积 + 1 全连接 |
| 卷积核 | 11×11、5×5、3×3 混用 | 全部 3×3 | 3×3（BasicBlock） |
| 通道变化 | 96→256→384→384→256 | 64→128→256→512→512 | 64→128→256→512 |
| 特征图尺寸 | 55→27→13→13→6 | 224→7（5 次 MaxPool 减半） | 224→56→28→14→7→GAP |
| 参数量 | 约 6000 万 | 约 1.38 亿 | 约 1170 万 |

### AlexNet（2012，深度学习引爆点）

创新亮点：

1. 激活函数改用 ReLU，替代之前常用的 sigmoid，缓解深层网络的梯度饱和问题，训练速度提升数倍；
2. 引入 Dropout 随机失活和数据增强，抑制模型过拟合；
3. 使用双 GPU 并行训练，把网络拆分到两块显卡上，解决当年显卡算力不足的痛点。

### VGG（2014，极简主义代表）

VGG 最核心的思想是"小核堆叠"：用连续两个 3×3 卷积等效一个 5×5 的感受野，参数量更少、非线性更强，网络设计极其规整，像搭积木一样重复相同的模块。

创新亮点：

1. 整套网络统一只用 3×3 卷积核，设计极简，可扩展性很强；
2. 证明"把网络做深"是提升模型能力非常有效的手段。

教训：三个巨型全连接层带来了巨大参数量，VGG-16 一亿多参数绝大多数都集中在全连接层。这个沉重的代价催生了后续两个重要技术：1×1 卷积（Network in Network），以及全局平均池化（GoogLeNet、ResNet 使用）。

### ResNet（2015，残差连接）

ResNet 解决了困扰学界很久的网络退化问题：单纯把网络堆深，训练误差反而上升——这不是过拟合，而是优化困难。

创新亮点：

1. 残差捷径 y = F(x) + x：网络不再学习从 x 直接映射到 y，而是学习残差 F(x) = y − x，优化难度大幅降低，网络可以做到几十上百层；
2. BatchNorm 正式铺开，稳定训练，让深层网络收敛变得容易；
3. 用全局平均池化（GAP）替换巨型全连接层，大幅砍掉参数量，ResNet-18 的参数量比 VGG 小一个数量级。

### 三条演变主线

**故事线1（参数量）：6000 万 → 1.38 亿 → 1170 万。** AlexNet 6000 万参数；VGG 为了加深网络，加上三个巨大全连接层，参数量暴涨到 1.38 亿，代价沉重；ResNet 用 GAP 替代全连接，直接砍掉绝大部分参数，ResNet-18 仅 1170 万。这个演进说明：单纯靠堆全连接层扩容参数性价比很低，"卷积 + 全局池化"的方案用更少的参数就能获得很强的特征能力。

**故事线2（卷积核）：大核 11×11 → 统一小核 3×3 → Bottleneck 引入 1×1。** AlexNet 开头直接上 11×11 大卷积核；VGG 证明多个 3×3 堆叠性价比更高；ResNet 深层版本引入 Bottleneck 瓶颈结构：1×1 降维 + 3×3 特征提取 + 1×1 升维，利用 1×1 卷积压缩通道，大幅降低中间 3×3 卷积的计算量，让几百层网络的计算开销可控。

**故事线3（深度）：8 层 → 16 层 → 152 层。** AlexNet 仅 8 层；VGG 把深度推到 16、19 层，但发现继续加深效果反而变差；ResNet 依靠残差跳跃连接打通梯度回传通路，梯度可以跳过多个层直接回传，解决了深度退化问题，把网络上限拉高到上百层。从此"更深"成为 CV 模型提升能力最常用的思路。

**总结：** 从 AlexNet、VGG 再到 ResNet，这三条主线共同构成了现代 CNN 发展最核心的探索历程：从最早期验证深度学习的可行性，到尝试堆叠深度、踩下全连接参数爆炸的坑，最后依靠残差连接解决深度瓶颈，同时搭配 BN、全局池化、1×1 卷积等手段，奠定了后续计算机视觉网络的设计范式。

## 扩展2：预训练模型浅层 vs 深层特征（ResNet-18）

### 1. 第一层特征图的通道响应有什么特点？

第一层 64 个通道绝大多数都有明显响应（L2 范数多在几十到几百），只有极少数接近 0 的"死通道"；而且响应强的通道集合在不同照片之间高度相似——说明第一层学的是边缘、颜色块这类通用底层特征，不挑图片内容。

### 2. 最后一层呢？和第一层有什么不同？

最后一层 512 个通道里只有少数响应强，大部分接近 0。另外特征图空间只有 4×4（第一层是 64×64），又经过多层 ReLU 和 BatchNorm，L2 绝对值比第一层小两个数量级，所以对比时看的是响应的相对分布（降序排序后的曲线形状），而不是绝对数值。

### 3. 不同图片在最后一层的激活有什么差异？

不同图片激活的通道集合明显不同——最后一层通道对应 ImageNet 学到的语义概念（某种纹理、物体部件等），图片内容不同，触发"专职探测器"的子集自然不同。

## 扩展3：Bottleneck 改造实验

### 1. 参数量的变化？

Bottleneck 把卷积参数量降到原来的 69.17%（23,584 → 16,312），但总参数量几乎没变（2,120,993 → 2,113,721）：卷积再省，全连接层才是参数大户，全连接没动，总参数就降不下去。

### 2. 训练速度的变化？

每轮 Bottleneck 大约慢 0.4 秒（22.3s → 22.7s）：层数变多，GPU 要跑更多小算子，开销反而略增。

### 3. 精度的变化？

原版更高。对比表（test acc）：原版 0.8709 > Bottleneck+BN 0.8253 > 裸 Bottleneck 0.7737。而且裸 Bottleneck 跨次运行结果不稳定：第一次训练 loss 钉死在 0.6932（正好是 ln2，二分类瞎猜的损失），test 只有 0.4962，完全没学起来；第二次重跑才到 0.7737。没有 BN 时，训练结果要看初始化的运气。

### 结论

1×1→3×3→1×1 这个结构本身不是问题（加上 BN 就能正常训练），真正缺的是 BN 带来的训练稳定性；但在这只有 3 个块的小网络上，加深带来的优化难度超过收益，还不如原来的简单结构。这也符合题目的提示：Bottleneck 是为几十上百层的深网络设计的省参数手段，小网络用不上。另外原版两次运行 test 是 0.8645 / 0.8709，本身也有 ±0.6 个百分点的波动——1 个百分点以内的差距不足以下结论。

## 扩展4：手搓 ResNet-18

### 1. 手搓版的参数量和论文对得上吗？

手搓版参数量 11,689,512，和论文的 11.69M 基本一致，说明结构搭对了。

### 2. 特征图尺寸从 224 一路变到 7，每次减半发生在哪里？

前两次减半在 stem：7×7 卷积 stride=2 管 224→112，MaxPool stride=2 管 112→56。后三次减半是 layer2/3/4 各自第一个 BasicBlock 的 stride=2 干的：56→28→14→7，正好五次减半。layer1 的 stride=1，尺寸不变。

### 3. 残差捷径的作用？去掉会怎样？

残差捷径解决深度网络的退化问题。如果去掉捷径，训练误差可能上升，梯度也更容易消失——网络深了之后，单纯堆层的优化难度会失控。这一点和扩展3的实验互相印证：裸 Bottleneck 多了几个 1×1 层就直接训不动，18 层的网络去掉捷径只会更严重。
