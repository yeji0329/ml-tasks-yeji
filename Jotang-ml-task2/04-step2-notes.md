# 实践2：猫狗分类器（趁热打铁六问）

### 1. 卷积层和全连接层有什么区别？

卷积层看图片时每次只看一小块局部区域，而且一套卷积核是整张图共用的，所以自带平移不变性（图案出现在哪里都能被识别出来），再加上权重共享，参数量很小；全连接层的每个神经元要和上一层的所有数字相连，没有局部观察，也没有平移不变性，参数量一下就上去了。我的网络里 16384→128 这一层就占了总参数的绝大部分。

### 2. 通道数为什么这样设计（3→16→32→64）？

输入图片的原始通道是 3，随着网络往下走，图片分辨率不断缩小，特征图上每个像素对应的原图区域变大。大图阶段只提取边缘、线条这类简单特征，少量通道就够用；图变小之后，为了描述复杂多样的组合特征，就要增加通道数量，用更多不同的特征提取器来记录不同的图案。

### 3. 尺寸计算公式代入自己的网络

输出 = (输入 + 2×padding − kernel) / stride + 1。

- 卷积：我的网络里 kernel=3、padding=1、stride=1，代入得 (输入 + 2×1 − 3) / 1 + 1 = 输入，所以卷积不改变宽高；
- MaxPool：kernel=2、stride=2，代入得 (输入 + 0 − 2) / 2 + 1 = 输入 / 2，所以每次池化宽高减半。

128 进网络，池化三次后变成 16，通道涨到 64，最后 Flatten 得到 64×16×16 = 16384。

### 4. 为什么越深的层特征图越小、通道越多？

网络越深，经过多次池化压缩，特征图分辨率变小，但感受野更大，能表达的复杂特征种类也更多，所以需要更多通道来存放各种不同组合的特征信息。

### 5. 为什么最后输出一个数、损失函数用 BCEWithLogitsLoss？

这个任务是猫狗二分类，只需要输出一个数表示样本是狗的概率，所以最后用 Linear 到 1。BCEWithLogitsLoss 相当于把 sigmoid 和 BCE 合到一个函数里算，数值上更稳定：如果分开算，当数值落到 sigmoid 两端的饱和区时梯度会变得特别小，容易出现梯度消失。

### 6. 数据增强为什么只加在训练集？

训练集做数据增强是为了不让模型死记硬背，防止过拟合、提高泛化能力。如果验证集也增强，每次评测的数据都不一样，分数会忽高忽低，没有可比性，就没法判断模型到底有没有变好。
