# Task1 简单神经网络：学习笔记

## 一、实验记录

- 数据：make_moons(n_samples=1000, noise=0.2, random_state=42)，两月牙交叉，线性不可分
- 划分：train / val / test = 600 / 200 / 200（train_test_split 两次切分 + stratify 分层抽样）
- 模型：MLP（2 -> 16 -> 8 -> 1），隐藏层后接 ReLU，输出层不加 Sigmoid（直接输出 logit）
- 训练：BCEWithLogitsLoss + Adam（lr=1e-3），full batch，1000 epochs
- 结果：Linear 对照组 val acc 0.8350；MLP val acc 0.9400，test acc 0.9850
- 混淆矩阵 [[98, 2], [1, 99]]，两类错误基本均衡

## 二、趁热打铁七问

**1. 为什么这个任务用 MLP，逻辑回归（线性模型）不够？**

逻辑回归是线性模型，决策边界是直线，而这个任务的数据分布是非线性的。若用直线去分两类点，无论怎么训练，拟合效果都不会好，精度上不去；MLP 带非线性激活函数，可以生成弯曲的决策边界，对非线性分布拟合得更好。实验也验证了这一点：Linear 的 val acc 卡在 0.835，MLP 到 0.940，test 0.985。

**2. 训练集、验证集、测试集各自做什么用？为什么测试集只能最后用一次？**

训练集用来学习模型参数，进行模型更新，让模型学习特征和目标之间的关系，相当于练习题；验证集在训练过程中对模型评估和调试，帮助筛选不同结构的候选模型、调超参数、早停防过拟合，相当于模考题；测试集评估模型的泛化能力，模拟模型在真实未知数据上的实际表现，相当于高考题。测试集只在最后使用一次，是因为若提前用，相当于把测试集数据泄露给了模型，最后的成绩是虚高的——测试集不再是全新陌生的数据，达不到测试效果。

**3. 为什么模型最后一层不加 Sigmoid，损失函数却叫 WithLogits？**

BCEWithLogitsLoss 相当于把 Sigmoid 和 BCELoss 合在一起算。模型输出的是 logits，损失函数内部先做 Sigmoid 再算二分类损失。如果模型最后再手动加一层 Sigmoid，概率就被压缩了两次，训练信号失真，容易出现数值不稳定甚至 loss 变 NaN；而且 sigmoid 饱和区的梯度本来就小，双重压缩会让梯度更难传回去。

**4. ReLU 在网络里起什么作用？没有它会怎样？**

ReLU 是非线性激活函数，核心作用是给神经网络引入非线性能力，让深层网络能拟合各种复杂的数据分布。没有它，无论多少层线性层叠加都等价于单层线性运算，网络只能拟合直线，学不出弯曲的决策边界，也处理不了非线性的规律。

**5. 验证/测试时为什么要 model.eval() + with torch.no_grad()？**

model.eval() 把模型切换为评估模式，关闭 Dropout、让 BatchNorm 停止训练时的更新逻辑，防止评估时还在随机丢神经元、统计量继续变化，使推理结果稳定；with torch.no_grad() 关闭梯度计算，推理时不需要反向传播更新权重，关掉梯度可以节省显存、加快运行速度。

**6. 怎么从 loss/acc 曲线上判断模型过拟合了？**

acc 曲线：训练集准确率持续上升，但验证集准确率升到一定高度后开始往下掉；loss 曲线：训练 loss 持续降低，验证 loss 先降后升，两条线之间的缝隙越来越大。出现这些信号就该早停或加正则化。

**7. 为什么保存模型用 state_dict()，而不是 torch.save(model) 整个存？**

state_dict() 只保存模型权重参数，相当于菜谱只存配方；torch.save(model) 保存的是整个模型对象，对环境、代码文件、类定义的依赖很强，一旦代码改动、文件路径变化，加载时很容易报错失败。只存 state_dict，配合代码里的类定义，可移植性更好。

## 三、踩坑实录

- Python 缩进是语法的一部分：括号内的行多一格、少一格空格都会 IndentationError，改代码时复制整行再改数字最稳
- 字母 O 和数字 0 太像：EPO0CHS、1eO3 两次翻车，而且变量名打错 Python 不报错、程序照跑（起了一个没人用的新名字），这种 bug 比报错难查得多
- Jupyter 的真相在磁盘文件和内核两处，浏览器只是视图：改了代码不生效、报错和代码对不上时，关掉全部标签页重开 + Restart and Run All
- 内核重启后所有变量清空，要从第一个 cell 按顺序重跑；import torch.nn as nn 只绑定 nn 这个名字，不会创建 torch 变量
- 模型保存用 state_dict，加载时先建同结构的新模型，再 load_state_dict 灌参数
