# Task4 拓展

## 拓展 3：Transformer 走出文本——以 ViT 为例

ViT（Vision Transformer，2020/2021）把 Transformer 搬到了图像分类上。

**输入是什么**：图像切成 16×16 的小块（patch），每块拉平后过一个线性层，变成和词向量一样的 embedding 序列。一张 224×224 的图变成 196 个"图像词"，外加一个专门用于分类的可学习向量 [CLS] 拼在最前面。因为注意力本身不感知顺序，这里也要加位置编码。

**Attention 在哪起作用**：和文本完全一样——每个 patch 都对其他所有 patch 做注意力。图像里的远距离关联（比如左上角的天空和右下角的湖面倒影）不需要卷积层层传递，一步就建立联系。

**与原论文的差异**：
1. token 来源不同：原论文输入是词嵌入 + 位置编码，ViT 是 patch embedding + 位置编码；
2. 结构不同：ViT 只用 Encoder（分类任务不需要 Decoder 逐个生成）；
3. 原论文用正弦位置编码，ViT 用可学习的位置编码；
4. 归纳偏置更少：CNN 自带"局部性、平移不变"先验，ViT 没有，所以小数据上不如 CNN，需要大数据预训练才发挥威力——这也反过来印证了 Transformer 的核心优势是通用性和可扩展性，而不是天然适合某种数据。

## 拓展 4：Encoder-only 与 Decoder-only

| | Encoder-only（BERT 为代表） | Decoder-only（GPT 为代表） |
|---|---|---|
| 结构 | 只保留 Transformer Encoder，双向注意力 | 只保留 Transformer Decoder，带因果掩码的单向注意力 |
| 训练目标 | 随机遮住 15% 的词，让模型还原（完形填空） | 永远预测下一个词 |
| 擅长任务 | 理解类：分类、情感分析、信息抽取、句子级语义 | 生成类：对话、写作、代码补全 |
| 看文本的方式 | 每个词同时看左右两边上下文 | 每个词只能看左边 |

**为什么不同任务选不同结构**：理解任务要完整语境——判断"这部电影真棒"是夸还是讽刺，得看全句甚至全文，双向 Encoder 天然合适；生成任务从左到右一个字一个字往外蹦，训练目标就是"见过的前文 → 下一个词"，单向 Decoder 和这个目标严格对齐，而且训练时和推理时的信息可见性一致（都看不到未来），不会出现训练作弊的问题。现在的大语言模型（GPT、LLaMA 等）几乎都选 Decoder-only，一个重要原因是"预测下一词"这个训练目标可以从互联网上任意文本无限构造数据，不需要人工标注。
